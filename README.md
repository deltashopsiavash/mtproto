# DELTA MTProto Panel v2

پنل مدیریت MTProto با نصب تک‌دستوری، ورود امن، داشبورد سرور، مدیریت کاربران، تنظیمات سرور، بکاپ و ایمپورت.

## نصب از GitHub

```bash
bash <(curl -Ls https://raw.githubusercontent.com/deltashopsiavash/mtproto/main/install.sh)
```

## امکانات نسخه v2

- وارد کردن مدت اعتبار با عدد روز، مثل `30`
- نمایش حجم به شکل مرتب و درصد مصرف
- ویرایش کاربر بعد از ساخت: نام، حجم، مصرف ثبت‌شده، تاریخ جدید، وضعیت و یادداشت
- بخش Settings برای تغییر نام کاربری و رمز پنل
- تنظیم دامنه/IP و پورت نمایش داده‌شده در لینک‌های پروکسی
- خروجی بکاپ JSON از همه کاربران و تنظیمات اصلی
- ایمپورت بکاپ و جایگزینی کاربران
- طراحی کامل جدید و واکنش‌گرا

> نکته: مصرف واقعی هر کاربر در این نسخه از دیتابیس پنل خوانده می‌شود و قابل ویرایش است. برای اعمال خودکار محدودیت حجم باید در مرحله بعد accounting/traffic enforcement به سرویس پروکسی اضافه شود.
