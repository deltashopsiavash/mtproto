# DELTA MTProto Panel

پنل مدیریت MTProto برای ساخت و مدیریت پروکسی‌های تلگرام با پنل وب، ساب‌لینک اختصاصی و ربات تلگرام دکمه‌ای.

## نصب و آپدیت

برای نصب از صفر یا آپدیت نسخه قبلی فقط همین دستور را روی سرور بزنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/deltashopsiavash/mtproto/main/install.sh)
```

در زمان نصب از شما این موارد پرسیده می‌شود:

- پورت ورود به پنل
- نام کاربری پنل
- رمز عبور پنل
- آی‌پی یا دامنه عمومی سرور
- پورت مشترک پروکسی‌ها
- پورت ساب‌لینک‌ها
- تگ اسپانسر اختیاری

بعد از نصب، پنل از این آدرس باز می‌شود:

```text
http://SERVER-IP:PANEL-PORT
```

ساب‌لینک‌های کاربران:

```text
http://SERVER-IP:SUB-PORT/s/USER_SECRET
```

## امکانات اصلی

- ساخت کاربر با نام، حجم و تعداد روز اعتبار
- همه کاربران روی یک پورت مشترک با secret جدا
- ویرایش نام، حجم، مصرف، تاریخ و وضعیت بعد از ساخت
- غیرفعال‌سازی واقعی secret بعد از اتمام حجم یا تاریخ
- حذف secret از کانفیگ MTProxy و ری‌استارت سرویس برای قطع دسترسی
- ساب‌لینک اختصاصی برای هر کاربر
- ساب‌لینک ریسپانسیو و مناسب موبایل
- بک‌گراند متحرک در صفحه ساب‌لینک
- تغییر رنگ بک‌گراند ساب‌لینک با دکمه‌های آبی، زرد و سبز
- کپی لینک پروکسی در پنل و ساب‌لینک
- Overview سرور، رم، CPU، دیسک، آنلاین‌ها و ترافیک کلی
- تنظیمات دامنه/IP، پورت پروکسی، پورت ساب، تم و اطلاعات ورود
- بکاپ و ایمپورت بکاپ
- ربات تلگرام دکمه‌ای برای ساخت/ویرایش/حذف/لیست کاربران

## منطق حجم در حالت یک پورت

این نسخه روی حالت **Shared Port** کار می‌کند؛ یعنی همه کاربران یک پورت مشترک دارند و فقط secret هر کاربر فرق دارد.

در MTProxy رسمی، ترافیک از سطح سیستم فقط بر اساس پورت دیده می‌شود و خود MTProxy معمولی آمار per-secret بیرون نمی‌دهد. برای جلوگیری از باگ نسخه‌های قبل، این نسخه دیگر ترافیک را بین همه کاربران پخش نمی‌کند.

منطق جدید:

- ترافیک پورت مشترک فقط به یک `secret` فعال نسبت داده می‌شود.
- وقتی کاربر از صفحه ساب‌لینک خودش دکمه «اتصال» را می‌زند، همان secret به عنوان مصرف‌کننده فعال ثبت می‌شود.
- اگر مصرف همان secret به سقف حجم برسد، همان کاربر غیرفعال می‌شود.
- secret کاربر تمام‌حجم/منقضی/غیرفعال از کانفیگ MTProxy حذف می‌شود.
- بعد از حذف secret، سرویس `mtpulse-shared` ری‌استارت می‌شود تا اتصال جدید با آن secret ممکن نباشد.
- ترافیک مبهم به کاربران دیگر اضافه نمی‌شود؛ بنابراین حجم کاربران آفلاین یا کاربران دیگر کم نمی‌شود.

> نکته فنی: دقت ۱۰۰٪ per-secret روی یک پورت فقط با موتور MTProxy لاگ‌دار/پچ‌شده یا موتور جایگزین دارای metrics per-secret ممکن است. این نسخه با MTProxy رسمی، جلوی مصرف اشتباه از بقیه کاربران را می‌گیرد و secret تمام‌شده را قطع می‌کند.

## روش درست استفاده برای ثبت مصرف

برای اینکه مصرف به secret درست بخورد، لینک ساب‌لینک هر کاربر را به خودش بدهید و کاربر از داخل همان صفحه روی دکمه «اتصال» بزند. این کار باعث می‌شود پنل بداند ترافیک بعدی مربوط به همان secret است.

## سرویس‌ها

```text
delta-panel
```

پنل اصلی وب.

```text
delta-sub
```

ساب‌لینک‌های عمومی کاربران.

```text
mtpulse-shared
```

سرویس MTProto مشترک روی یک پورت.

لاگ‌ها:

```bash
journalctl -u delta-panel -f
journalctl -u delta-sub -f
journalctl -u mtpulse-shared -f
```

## مسیر نصب

```text
/opt/delta-proxy-panel
```

دیتابیس:

```text
/opt/delta-proxy-panel/delta.db
```

فایل تنظیمات:

```text
/opt/delta-proxy-panel/.env
```

## خطای 404 در نصب

اگر دستور نصب خطای 404 داد، یعنی فایل `install.sh` روی branch `main` ریپو نیست یا هنوز push نشده است. فایل‌های همین سورس را داخل ریپو بگذارید و push کنید.
