# DELTA MTProto Panel

پنل مدیریت MTProto برای ساخت و مدیریت پروکسی‌های تلگرام با پنل وب، ساب‌لینک اختصاصی و ربات تلگرام دکمه‌ای.

## نصب و آپدیت

برای نصب از صفر یا آپدیت نسخه قبلی فقط همین دستور را روی سرور بزنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/deltashopsiavash/mtproto/main/install.sh)
```

در زمان نصب از شما این موارد پرسیده می‌شود:

- پورت ورود به پنل
- نام کاربری پنل
- رمز عبور پنل
- آی‌پی یا دامنه عمومی سرور
- پورت مشترک پروکسی‌ها
- پورت ساب‌لینک‌ها
- تگ اسپانسر اختیاری

بعد از نصب، پنل از این آدرس باز می‌شود:

```text
http://SERVER-IP:PANEL-PORT
```

ساب‌لینک‌های کاربران هم از پورت ساب باز می‌شوند:

```text
http://SERVER-IP:SUB-PORT/s/USER_SECRET
```

## امکانات پنل

- داشبورد Overview برای وضعیت سرور، رم، CPU، دیسک، آنلاین‌ها و ترافیک کلی
- مدیریت کاربران و پروکسی‌ها
- ساخت کاربر با نام، تعداد روز اعتبار و حجم GB/MB
- ویرایش کاربر بعد از ساخت
- تغییر حجم، تاریخ، مصرف ثبت‌شده، نام و وضعیت فعال/غیرفعال
- حذف کاربر
- کپی لینک پروکسی و ساب‌لینک
- حالت Shared Port: همه کاربران روی یک پورت مشترک هستند و secret اختصاصی دارند
- تنظیم IP یا دامنه عمومی برای لینک‌ها
- تنظیمات پنل شامل تغییر نام کاربری و رمز
- بکاپ و ایمپورت بکاپ
- ری‌استارت سرویس پروکسی از پنل
- تم دارک/لایت

## ساب‌لینک اختصاصی کاربر

هر کاربر یک صفحه اختصاصی دارد که داخل آن می‌تواند موارد زیر را ببیند:

- نام کاربر
- پورت پروکسی
- وضعیت فعال یا غیرفعال
- روزهای باقی‌مانده
- حجم باقی‌مانده
- حجم مصرف‌شده
- لینک اتصال پروکسی
- دکمه کپی لینک پروکسی
- تغییر رنگ بک‌گراند ساب‌لینک با سه رنگ آبی، زرد و سبز

## ربات تلگرام

ربات به‌صورت دکمه‌ای کار می‌کند و بعد از تنظیم توکن و Chat ID در بخش Settings پنل فعال می‌شود.

امکانات ربات:

- ساخت کاربر مرحله‌ای با دکمه‌ها
- دریافت تعداد روز
- انتخاب واحد حجم GB یا MB
- دریافت حجم
- دریافت نام کاربر
- ساخت پروکسی و نمایش لینک‌ها
- لیست همه پروکسی‌های ساخته‌شده
- مشاهده جزئیات هر پروکسی
- تغییر حجم
- تغییر تاریخ
- ریست مصرف
- فعال/غیرفعال کردن
- حذف کاربر
- تنظیمات سرور و پنل مشابه سایت
- بکاپ گرفتن از کاربران و تنظیمات

بعد از تنظیم ربات، داخل تلگرام بزنید:

```text
/start
```

## نکته درباره مصرف حجم

در حالت Shared Port همه کاربران روی یک پورت مشترک هستند. به همین دلیل مصرف واقعی کل پورت از سیستم گرفته می‌شود، اما تفکیک دقیق مصرف هر secret در MTProxy رسمی به‌صورت مستقیم وجود ندارد. پنل مصرف کاربر را نمایش و مدیریت می‌کند و ترافیک کلی پورت مشترک را هم از سیستم می‌خواند.

## سرویس‌ها

این پروژه دو سرویس systemd می‌سازد:

```text
delta-panel
```

برای پنل اصلی وب.

```text
delta-sub
```

برای ساب‌لینک‌های عمومی کاربران.

دستورهای کاربردی:

```bash
systemctl status delta-panel
systemctl status delta-sub
journalctl -u delta-panel -f
journalctl -u delta-sub -f
```

## مسیر نصب

فایل‌های پروژه در مسیر زیر نصب می‌شوند:

```text
/opt/delta-proxy-panel
```

دیتابیس SQLite:

```text
/opt/delta-proxy-panel/delta.db
```

فایل تنظیمات سرویس:

```text
/opt/delta-proxy-panel/.env
```

## رفع خطای 404 در دستور curl

اگر این دستور خطای 404 داد:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/deltashopsiavash/mtproto/main/install.sh)
```

یعنی فایل `install.sh` هنوز روی branch `main` گیت‌هاب پوش نشده یا ریپو private/اشتباه است. فایل‌های همین سورس را داخل ریپو بگذارید و push کنید.
